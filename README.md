# Togle

Togle is an AI assistant for video calls. It runs on your computer, works with any call app, and:

- suggests what to say when someone asks you something, using your documents and what's on your screen
- writes the notes when the call ends
- keeps an agent for each kind of call, which learns your work over time
- types what you say into any app with dictation

The app's source code will be published here once it's ready.

## Togle Microphone

Noise cancellation and voice isolation are a separate paid product, Togle Microphone. It isn't open source and isn't part of this repository.
